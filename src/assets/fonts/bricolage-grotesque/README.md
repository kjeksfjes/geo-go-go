# Bricolage Grotesque

The unmodified Google Fonts Latin variable WOFF2 is self-hosted for the brand at weight 600 and width 84, and Explore country names and quiz headings at weight 400 and width 100. The font supports weight 200–800, width 75–100, and optical size 12–96. CSS uses the real weight and width axes; optical sizing remains automatic.

Webfont source: [Google Fonts CSS](https://fonts.googleapis.com/css2?family=Bricolage+Grotesque:opsz,wdth,wght@12..96,75..100,200..800&display=swap), immutable asset `https://fonts.gstatic.com/s/bricolagegrotesque/v9/3y996as8bTXq_nANBjzKo3IeZx8z6up5L-iNGfyOPPs.woff2`. License source: [Google Fonts repository](https://github.com/google/fonts/tree/6ce172f74aa355ea43eb964fa4a91570a4d3064d/ofl/bricolagegrotesque), revision `6ce172f74aa355ea43eb964fa4a91570a4d3064d`. The Latin subset covers English and Norwegian text, including Æ/Ø/Å.

The original `OFL.txt` accompanies the font. No third-party font service is contacted at runtime.
