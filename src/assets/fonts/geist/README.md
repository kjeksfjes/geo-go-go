# Geist

The unmodified upright Google Fonts variable font is self-hosted for UI text and controls at weight 480 for small text and compact controls, and weight 380 for larger body text and answer inputs. The tagline uses weight 400; revealed and submitted answer names use emphasis weight 600. Its supported weight range is 100–900. Source: [Google Fonts](https://github.com/google/fonts/tree/7085eb89a950e85db5b166b7a58d414544b4140c/ofl/geist), revision `7085eb89a950e85db5b166b7a58d414544b4140c`, file `Geist[wght].ttf`. The full font includes English and Norwegian glyphs, including Æ/Ø/Å.

The original `OFL.txt` accompanies the font. No third-party font service is contacted at runtime.
