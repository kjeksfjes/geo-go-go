# EB Garamond

The unmodified italic Google Fonts variable WOFF2 subsets are self-hosted for water names, including their measurement text. The supported weight range is 400–800; large ocean names use weight 600. Latin and Latin Extended cover the English and Norwegian names and additional Latin diacritics in the reviewed marine labels.

Webfont source: [Google Fonts CSS](https://fonts.googleapis.com/css2?family=EB+Garamond:ital,wght@1,400..800&display=swap), downloaded 2026-10-11. Immutable assets:

- [EBGaramond-Latin-Italic-Variable.woff2](https://fonts.gstatic.com/s/ebgaramond/v33/SlGWmQSNjdsmc35JDF1K5GRweDs1ZyHKpWg.woff2)
- [EBGaramond-LatinExt-Italic-Variable.woff2](https://fonts.gstatic.com/s/ebgaramond/v33/SlGWmQSNjdsmc35JDF1K5GRweDU1ZyHKpWiGIg.woff2)

The original `OFL.txt` accompanies the fonts. License source: [Google Fonts repository](https://github.com/google/fonts/tree/f8c1d3d6cc75e30d77130bdcbfbff27e3b6233fe/ofl/ebgaramond), revision `f8c1d3d6cc75e30d77130bdcbfbff27e3b6233fe`. No third-party font service is contacted at runtime.
