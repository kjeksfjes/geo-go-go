# Geo Go Go

An interactive world-map game for exploring countries and testing your geography knowledge.

[**Play Geo Go Go →**](https://kjeksfjes.github.io/geo-go-go/)

[![Latest release](https://img.shields.io/github/v/tag/kjeksfjes/geo-go-go?sort=semver&label=latest%20release)](https://github.com/kjeksfjes/geo-go-go/tags) [![Changelog](https://img.shields.io/badge/changelog-view-59636e)](CHANGELOG.md)

Built with Vue 3, TypeScript, Vite, Natural Earth Admin-0 Map Units, `d3-geo`, and `flag-icons`.

The map starts with Natural Earth's 1:50m Admin-0 Map Units. A **High detail** toggle lazily loads the corresponding 1:10m units when requested. This keeps the initial download and render light, avoids changing geometry in the middle of a gesture, and makes coastlines and small countries clearer at close range when desired. After each resolution has rendered once, its projected SVG paths are cached so later switches are immediate at the current map size and projection. The **Bathymetry** toggle adds seven noninteractive ocean-depth bands (200m, 2,000m, 3,000m, 4,000m, 5,000m, 6,000m, and a darkest 7,000–10,000m trench band) behind the country layer for relief-style experiments. The adjacent **Relief** toggle adds six similarly simplified elevation bands (500m, 1,000m, 1,500m, 2,250m, 3,000m, and 4,000m) without changing map interaction. The map also shows major ocean names at world scale and introduces names of seas, gulfs, bays, and other smaller waters as you zoom. These labels are noninteractive and follow the active projection and map movement. The **Water names** toggle can hide them; labels also disappear temporarily during map dragging and zooming so they do not distract from motion.

On touch-first devices, rapid two-finger zooms and one-finger pans can temporarily use a lower-density canvas preview. Invisible country hit paths pause during the preview; answer highlights and neutral land remain visible. Normal hit targets return after the gesture. A coverage-valid cached raster bridges the wait for full-density detail; panning retains the normal magnification limit to avoid enlarging the overview excessively, with “Restoring detail” shown until a sharp replacement is available. Slow pinches, desktop dragging and wheel/trackpad zoom, and the SVG fallback retain their normal rendering. A temporary touch-device badge switches between Normal zoom, Fast zoom preview, and SVG renderer so the user can see when the experiment is active. After a pinch or one-finger pan finishes, tap that badge to copy only the most recently completed gesture and its short settling window. The report is explicitly labeled pinch or pan; pan reports include direction and relative camera displacement. The report includes map settings, browser/viewport information, RAF timing gaps, preview/fallback samples, timestamped preview/renderer/displayed-density transitions, and worker round trips. Transition summaries identify fast-mode exits and re-entries while fingers are still pinching, separating them from the normal return after release. It is kept only in memory and is not sent anywhere automatically; unsupported long-task timing is explicitly marked unavailable. The user has confirmed much improved high-detail zoom and pan responsiveness on their iPhone; bathymetry testing remains pending. The development changes are not yet released.

The scale bar shows an approximate distance near the center of the current map view. It is visible by default, can be hidden in map settings, and supports metric, imperial, and nautical units. Metric is the default; both visibility and units are remembered between visits.

Settings are grouped into **Map appearance** (High detail first, followed by Bathymetry, Relief, Water names and Projection), **Quiz**, and **Navigation & scale**. Quiz preferences stay available in every mode and identify which quiz they affect. **Reveal clicked country names** shares the Find the country quiz’s existing **Always show** preference. In its answer card, **What did I click** reveals the clicked country and **Always show** control; enabling that control checks it and saves the preference, while disabling it hides the clicked country again. Desktop settings use two columns, with Map appearance on the left and Quiz above Navigation & scale on the right. Language stays in the desktop header and appears at the top of mobile settings. Help stays inside each setting’s card, with mode labels for quiz preferences. **Limit country zoom** affects automatic country framing; manual zoom remains unrestricted by that preference. The single-column mobile panel, and shorter desktop windows, scroll only when needed to fit the available screen height.

It defaults to a conventional Mercator projection. Mercator preserves local shapes and angles well, while enlarging areas toward the poles in the familiar way. The World view wraps horizontally at every zoom level when panning across the map edge.

## Run locally

All country display names are supplied by the app in `src/data/country-names.json`, keyed by canonical country identity with explicit `en` and `nb` strings. Country cards, quiz questions, feedback, hover labels, and accessibility labels share this catalog; browser/OS language databases and flag codes do not supply names. Norwegian state names follow the Bokmål forms in [Språkrådet's state-name list](https://sprakradet.no/stedsnavn-og-navn-pa-statsorgan/navnelister-norsk-skrivemate/utanlandske-stadnamn-navn-pa-stater-og-sprak-transkripsjon/navn-pa-stater/), with explicit app labels for territories and non-state identities. `npm run check:country-names` verifies exact identity coverage and nonempty translations in both languages, and runs as part of `npm run build`. New country identities must include both names; there is no source-name or browser-translation fallback for known countries.

```sh
npm install
npm run dev
```

Open the local URL printed by Vite, then hover, focus, or click a country. Use the EN/NO control to switch between English and Norwegian Bokmål. The app starts in the browser's language when supported and remembers a manual choice. Scroll over the map to zoom around the pointer; selecting a country smoothly zooms the map to its bounds. Drag a zoomed map to pan, or switch between Mercator, Winkel Tripel, Equal Earth, and Natural Earth projections with the map control. Regional Equal Area uses an azimuthal equal-area projection; Europe uses a 10°E, 52°N origin and fits the displayed European map units. Western Europe and Eastern Europe have explicit fit frames. The hierarchical region selector can isolate and focus a continent or a smaller subregion. Projected paths are reused when the projection and display geometry are unchanged; region-specific views may need new paths. The selector tree is navigation, not a source of geographic inheritance: Europe uses Natural Earth's UN-style region classification, whereas Western Europe is a separate playable grouping that retains Greenland. Its dropdown uses `@zanmato/vue3-treeselect` for tree navigation and single selection.

Regional views limit zoom-out and panning to the selected area with some surrounding space. Nearby land outside the region appears in a quieter color for orientation but remains non-interactive; only the selected region contributes quiz countries. The World view retains unrestricted global navigation.

The **Find the country** mode shows a flag and country name from the active region. Click its map location to answer. Each correct first attempt earns one point; after every answer, use **Next country** to continue. A round asks each eligible state once; changing regions inside a quiz starts a new round with confirmation only if the current round is unfinished and beyond its first question. A country's principal map unit must belong to the region for it to become a regional question; overseas units remain visible and interactive but do not make an otherwise out-of-region parent country a question. Explicit playable groupings keep their own membership rules. Territories remain visible on the map but are not used as quiz questions. After an answer, clicking the map or pressing Space also advances, so the player can continue without moving back to the button. Tiny eligible countries get neutral screen-sized dots while their real shapes are too small to use. A dot selects its country; overlapping dots combine into a zoom target until their locations can be distinguished. The dots never identify the current answer, and the underlying geography stays unchanged.

The **Name the country** mode frames and highlights a country from the same active-region quiz pool without displaying its name or flag. Type in the country-answer field to filter the app's English or Norwegian names, then use arrow keys and Enter or tap a suggestion to submit. Matching ignores case and accents, with prefix matches first. Turkey is displayed in English and Tyrkia in Norwegian; Türkiye/Turkiye also finds that country. Clearing the field closes suggestions. **Skip** finishes the current question for zero points and shows a Skipped card before **Next country**; use **Cmd+Enter / Ctrl+Enter** from the answer field as a shortcut. Answers use canonical country identities, and all eligible regional names remain available throughout the round. In settings under **Quiz → Answer suggestions**, choose **Selected region** or **All countries**. All countries broadens the answer list to every quiz-eligible country while retaining regional questions; the preference is remembered and defaults to Selected region. Both quiz preferences are available in every mode, with notes identifying which quiz they affect. An outside-region **My guess** temporarily shows the country globally, and Next returns to the round’s selected region. After submission, the question heading stays in place and the chosen name remains in a read-only field. Correct answers receive green confirmation; wrong answers receive a red field border. The **Reveal answers automatically** quiz preference controls showing the correct name after wrong guesses and skips, is remembered separately from Find the country, and defaults off. **Show answer** reveals a hidden answer for the current question. **Always show** enables the shared saved preference and displays a check. Turning it off hides the current revealed answer and restores **Show answer**, matching Find the country’s clicked-answer controls. Hidden answers also stay unnamed in map tooltips and accessibility labels. Scoring, Next and replay follow the same quiz flow. After a wrong answer, **My guess** focuses the chosen country without changing the answer or score. The Reka UI combobox loads only when this mode is used; desktop users can answer continuously from the keyboard, while touch users open the software keyboard deliberately. A map tap also focuses the answer field while a Name the country question is awaiting a guess; panning and pinching do not focus it.

Natural Earth map units are rendering parts, not automatically separate quiz areas. By default, parts sharing one quiz identity are dissolved into one geographic interaction unit, removing internal administrative edges (as with Bosnia and Herzegovina, Serbia, and Belgium). The small opt-in list in `src/data/meaningful-map-units.json` keeps genuinely distinct components separate: mainland France and French Guiana, for example, remain separate geographic units tied to the same France answer. Hover and click target the complete geographic unit; in Explore, the clicked unit highlights strongly while other units of the same quiz identity highlight softly. Answer checking and the country card use the shared quiz identity. The country card can also show the selected component's own name and a smaller educational type label.

Each quiz mode keeps its own round for the current app session. Switching to Explore or the other quiz mode pauses the round; returning restores its region, question order, score, submitted answer or skip state, revealed names, and any typed Name the country draft. A brief resume note identifies the restored region. Returning to an untouched first question starts a fresh round in its original region, without a resume note; a first answer or skip counts as progress and is preserved. Changing regions in Explore does not replace paused quizzes. **Restart quiz** explicitly starts over; restart asks for confirmation after the first question of an unfinished round, and region changes use the same rule, proceeding immediately on the first question even after an answer or skip. Completed rounds remain on their results until replay. Reload recovery is deferred in TASK-008.

Explore-mode selection has a separate, small camera/selection policy in `src/data/selection-behavior.json`. Clicking a configured main country unit highlights all of that quiz identity's parts, while clicking a named component highlights that component strongly and its siblings softly. Nearby components can share a camera footprint (for example mainland Italy, Sicily, and Sardinia); distant components keep their own click-to-zoom focus. Hover is broader: every visible part sharing a quiz identity highlights together, even when its camera focus remains local. In quiz feedback, a country's parts highlight together by default, whether the answer is correct or wrong. The same config lists distant components that retain a secondary highlight when the main country is clicked, and become primary themselves when clicked. These visual groups do not change quiz identity or camera focus.

## Geographic data

Marine names and approximate label positions come from Natural Earth's [1:10m Geography Marine Polygons](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-physical-labels/). `scripts/import-marine-labels.py` combines the source geometry with the reviewed English and Norwegian Bokmål names in `scripts/marine-label-names.json`, then generates `src/data/marine-labels.json`. Every label has an explicit value in both languages; established Norwegian exonyms are used where verified, while other labels intentionally retain the authoritative international or local name. The five ocean anchors are placed separately because the source divides oceans into multiple polygons and some span the map seam. The review decisions and sources are summarized in [`docs/marine-label-audit.md`](docs/marine-label-audit.md).

The bathymetry POC uses Natural Earth's nested 1:10m vector bathymetry bands. `scripts/import-bathymetry.py` merges and simplifies the selected 200m, 2,000m, 3,000m, 4,000m, 5,000m, 6,000m, and 7,000m source files into `src/data/bathymetry.json`; the deepest contour supplies one shared 7,000–10,000m trench treatment. The bands are projected by the same D3 projection and transformed by the same pan/zoom group as the country geometry; they do not participate in hit-testing or quiz behavior.

The land-relief POC derives six vector elevation bands from NOAA NCEI's ETOPO 2022 ice-surface model. `scripts/import-relief.py` uses interpolated contours from a sampled NetCDF grid, removes tiny fragments, and simplifies the result into smooth SVG-ready geometry in `src/data/relief.json`. At runtime, the projected bands are clipped to the currently visible geographic units, so regional filtering and regional display geometry remain authoritative. Country borders and translucent interaction states are rendered independently above the relief, preserving some elevation contrast during hover and quiz feedback.

The checked-in map assets come from Natural Earth 5.1.1 **Admin-0 Map Units** at [1:50m](https://www.naturalearthdata.com/downloads/50m-cultural-vectors/50m-admin-0-details/) and [1:10m](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-0-details/). `scripts/import-natural-earth.py` converts their shapefiles to compact GeoJSON. The 50m table defines the unit IDs and metadata; the 10m file supplies geometry for the same units, keeping detail switches stable. `GU_A3` identifies a source map unit, `ADM0_A3` groups units into a country/quiz identity, and `SOV_A3` records the separate sovereign relationship. Dependency parent links are optional. Natural Earth's `REGION_UN` and `SUBREGION` fields provide the canonical, broadly UN M49-style geography. Custom game groupings (Western Europe, Eastern Europe, Balkans, the three Asia practice groups) are overlays, never inherited into a parent continent. Western Europe (24 quiz countries) and Eastern Europe (22) are mutually exclusive game groups. Eastern Europe uses the Norwegian Wikipedia article's [country table](https://no.wikipedia.org/w/index.php?title=Øst-Europa&oldid=25912362#Land), adapted to place Greece in Western Europe and retain Turkey in Eastern Europe. Western Europe contains the remaining canonical European country identities, including the Nordic states, Spain, Portugal, Italy, Greece, and the Mediterranean microstates; Greenland and the Faroes retain their Explore membership. Balkan remains a smaller practice group overlapping both broad groups, with Greece in its western overlap and Turkey in its eastern overlap. These are explicit game policies rather than strict UN subregions; every country eligible for the Europe quiz belongs to exactly one broad group. Turkey remains an additional Eastern Europe question without changing its canonical continent membership. Initial views focus on the practice area without splitting Russia or Turkey into new quiz identities. State eligibility is a separate game rule.

Asia's practice groups are **Middle East & Western Asia / Midtøsten og Vest-Asia** (20 quiz countries), **Central & South Asia / Sentral- og Sør-Asia** (13), and **East & Southeast Asia / Øst- og Sørøst-Asia** (17). They cover all 49 countries in the Asia quiz exactly once. The western group uses the source's Western Asia classification plus Iran and Egypt; the central/southern group combines Central and Southern Asia excluding Iran, and the eastern group combines Eastern and South-Eastern Asia. Egypt remains an extra practice-group member while its canonical continent stays Africa. Russia's principal unit remains European and is not added to the Asia quiz. Hong Kong, Macao, Siachen, and the Australian Indian Ocean Territories retain their existing Explore-only treatment. Each wider group has an explicit regional projection frame; country identities, state eligibility, and geometry are unchanged.

Natural Earth's "Geo unit" type does not say whether a split should be an independent game area: it marks Vojvodina and French Guiana alike. The explicit meaningful-unit list provides that semantic decision. The generated `combined-geographic-units-50m.json` and `combined-geographic-units-10m.json` contain dissolved geometry for unlisted multi-part identities; regenerate them with `scripts/build-geographic-units.py` after changing the map-unit list.

Extra 10m geographic units within an existing country (such as Brčko District and Iraqi Kurdistan) are retained in `ne-10m-canonical-fill-geometries.json` and dissolved into that country's detailed geometry, even when it has only one canonical 50m unit. They do not create extra quiz answers. `country-taxonomy.json` also records curated quiz identity overrides, so source regeneration preserves choices such as Åland belonging to Finland's quiz identity.

Other previously omitted 10m pieces are retained in generated `supplemental-land.json` as neutral visual land at both detail levels. They have no country/quiz identity or regional membership; their fill blocks clicks on underlying country geometry while affiliations are undecided. Both renderers share the same small SVG land pass.

`scripts/build-geographic-units.py` also generates `supplemental-country-geometries-50m.json` and `supplemental-country-geometries-10m.json`. These sparse overrides exclude supplemental land and replace adjoining coarse/detailed difference pieces through one shared repair footprint for neighboring countries. The footprint includes coastal endpoints and seaward edges, and follows natural geometry intersections rather than a rectangular crop, so both sides of national borders join the detailed supplemental outline together. The generator checks shared-edge coverage and coastal contacts, and rejects newly overlapping country shapes. The overrides exclude supplemental land from country/component geometry wherever the source overlaps it, so low-detail fill, outlines, highlighting, hit-testing and focus use the same area separation as high detail. Supplemental boundaries retain their detailed source shape at both resolutions; no simplification may erase a small area. Quiz unions start from the corrected Explore geometry and then apply only the existing curated merge policies. Exact source defects are repaired through `scripts/map-geometry-corrections.json`, with assertions that stop regeneration if the expected source coordinates change. See [the boundary audit](docs/supplemental-boundary-audit.md) for provenance and verification.

Claim boundaries are separate noninteractive linework in `disputed-boundaries.json`. `scripts/import-disputed-boundaries.py` extracts the explicitly curated Hala’ib Sudanese claim line from Natural Earth’s 10m Admin-0 Boundary Lines – Disputed Areas source. A shared dashed SVG overlay sits above country fills and highlights in both rendering modes and detail levels, respects region visibility and horizontal map copies, and is hidden in quiz mode. It does not change land, country affiliations, hit targets or quiz answers.

Public Explore area labels are separately opted in through `supplemental-area-labels.json`. The two Korean DMZ source pieces form one dissolved hover, click, and keyboard-focus shape with a single area card; their shared dividing line is separate, noninteractive dashed linework. `scripts/build-geographic-units.py` generates these grouped Explore shapes and dividing lines in `supplemental-area-geometries.json`, preserving the individual source pieces for quiz policies. UNDOF, Akrotiri, Dhekelia and Bir Tawil have their own area cards without country selection. Bir Tawil’s card explains that neither Egypt nor Sudan claims it; it stays separate in Explore and merges into Sudan’s shape only for the quiz. Guantánamo's card identifies the US-administered leased area; its explicitly curated `quizEntityId` associates it with Cuba for Explore country highlighting, without asserting US sovereignty or introducing a new quiz answer. All named areas' dashed boundaries share Baikonur's internal-boundary color, width, and dash pattern in `mapPalette.ts`, with the same SVG pass above both renderers at both detail levels.

`quiz-map-merges.json` separately defines quiz-only simplifications: Akrotiri and Dhekelia merge into Cyprus, Guantánamo into Cuba, Baikonur into Kazakhstan, the restored UNDOF strip into Syria, and Bir Tawil into Sudan. Bir Tawil’s quiz-only merge keeps the country-selection border near the 22nd parallel; it is a game simplification, not an assertion that Sudan claims or administers the area. The UNDOF policy applies only to source piece `SYU`, not to the wider Golan boundary. The Korean DMZ's southern source half (`KNX`) merges into mainland South Korea, and its northern half (`KNZ`) into North Korea, retaining the dividing line while hiding the outer buffer boundaries. Each policy names its exact `geographicUnitId`; South Korea targets `subunit:KOR`, leaving Jeju and other components unchanged. Explicit `excludeSourceIds` remove coarse-boundary overlap with the opposite DMZ half in quiz mode only.

`scripts/build-geographic-units.py` also generates `quiz-merged-geometries-50m.json` and `quiz-merged-geometries-10m.json`, keyed by geographic unit ID, from country/component geometry and the curated supplemental/lease shapes. The quiz uses these dissolved geometries for country fill, outline, hit-testing, focus, and answer feedback, omitting the separate area overlays and internal boundaries. Explore source geometry, labels, and sovereignty metadata remain unchanged; other buffer zones and disputed areas are not automatically merged. Quiz projection variants reuse unchanged Explore paths and project only the merged units, keeping their fitting coordinate system stable. The canvas worker retains the current scene's parsed paths for reuse on updates; compatible projection/viewport updates keep a front frame visible until its replacement arrives.

Curated `leasedAreas` in `meaningful-map-units.json` retain leased land such as Baikonur as clickable components, with subtle internal boundaries rather than water-filled holes. They preserve their host country's quiz identity; the component label describes the lease operator separately. After importing new source geometry, run `node scripts/build-leased-areas.mjs` to regenerate `leased-area-geometries.json` from the matching 10m country holes. Both detail levels use the same small lease boundary so clicking and highlighting remain consistent.

Selected [Natural Earth Admin-0 Map Subunits](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-0-details/) at 50m and 10m supply source geometries and names for places within a single map unit, including Alaska, Hawaii, Corsica, Tasmania, Jeju, Hainan, and Japan's main islands. `SU_A3` identifies the subunit, `GU_A3` links it to the parent map unit, and `ADM0_A3` links it to the country/quiz identity. Only the subunit IDs opted in by `meaningful-map-units.json` become named components. The importer `scripts/import-meaningful-subunits.py` dissolves all other subunits of each selected map unit into one unnamed interactive remainder, so source splits do not automatically become educational components. The same config holds a small set of optional English/Norwegian name and type overrides. Natural Earth's `TYPE` field is usually only "Geo unit" or "Geo subunit," not a useful educational label such as "State" or "Archipelago"; informative source types are used when available, and otherwise a curated type may be shown or omitted. The remainder of each selected map unit is retained as an interactive geographic unit, so no country geometry is discarded. Subunit selection never changes the country used for quiz answers.

Some named components are not separate Natural Earth Admin-0 subunits. Crete and the three Caribbean Netherlands islands use [Natural Earth 1:10m Admin-1 States and Provinces](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-1-states-provinces/) names and boundaries. The importer uses those boundaries to identify complete Admin-0 coastline polygons at each map resolution, preserving the source country outline without a rough crop. `independentAdmin1RegionsByMapUnit` records these explicit semantic choices; `sourceSubunitIdsAt10m` reconciles source subunit IDs that split differently between 50m and 10m. Regeneration takes both Admin-0 subunit shapefiles and the 10m Admin-1 shapefile.

For a map unit with regional display geometry, the importer removes selected components from the regional remainder too. Kaliningrad is therefore separate from the rest of Russia without being drawn twice in the Europe view; the existing dashed Europe–Asia division remains on the Russian remainder.

`independentCoastlineComponents` explicitly names whole islands that are not separate source subunits. Seed points identify single polygons in the checked-in 10m map-unit atlas; the importer removes each polygon from its existing parent component and retains the same small shape at 50m when the coarse source omits it. Big and Little Diomede use this mechanism, with their Russia/USA identities and parent map-unit region membership preserved. Explore hover labels and the existing country card show component names; Little Diomede’s type text mentions the Diomede / Inalik community. Naming follows the [National Park Service](https://home.nps.gov/anch/learn/historyculture/how-close-is-alaska-to-russia.htm), [National Archives community guide](https://www.archives.gov/files/research/native-americans/communities/alaska-nativecommunities-guide.pdf), and [Store norske leksikon](https://snl.no/Diomedes%C3%B8yene). No permanent map labels or new quiz identities are added.

Natural Earth does not split Russia's European and Asian territory into map units. The Europe view therefore uses an optional **regional display geometry** for Russia at both resolutions. It is derived by intersecting the original Natural Earth Russia map unit with the European side of [Alexandr Trubetskoy's Europe–Asia boundary](https://sashamaps.net/resources/europe-asia-boundary/), following the Caucasus/Caspian, Ural River and Ural Mountains toward the Kara Sea. The source [GeoJSON boundary](https://github.com/sashatrubetskoy/asia_europe_border) is used with attribution. The artificial closing edges of the European-side polygon lie outside Russia; the cut through Russia follows the published geographic boundary, not a rectangular crop or SVG mask. The European Russia shape is filled separately from its outline: true Natural Earth edges retain the ordinary border style, while the cut through Russia is drawn as a subtle dashed geographic-division line.

`scripts/build-regional-display.py` generates the separate 50m/10m override assets from the boundary GeoJSON and the checked-in Natural Earth units. The base Natural Earth geometries are never modified. Region-specific geometry is used consistently for projection fitting, drawing, hit-testing and click-to-zoom; the map-unit ID and Russia quiz identity remain unchanged. Other transcontinental units such as Turkey and Kazakhstan have no override yet and may need their own geographic treatment later. To regenerate, install Shapely for the build script, download the boundary project's GeoJSON export, then pass its file path to `python scripts/build-regional-display.py`.

The detailed layer is matched back to 50m map-unit IDs, so switching resolution cannot change the selectable unit set. Detailed geometries pass a spherical-area sanity check; malformed features fall back to the safe 1:50m unit.

## Architecture at a glance

Data flows from geographic units and quiz identities through a D3 projection into a painted map and a separate interaction layer. The map reports clicks back to the app; the app owns selection and quiz state.

- **Data and rules:** `src/data/countries.ts` links Natural Earth map units, meaningful geographic components, and quiz identities. `src/data/regions.ts` defines geographic membership and playable groups; `src/data/quizCountries.ts` decides which identities can be questions. Curated exceptions live in the JSON configuration under `src/data/`.
- **App state:** `src/App.vue` owns mode, active region, detail level, and the selected identity/component. `src/composables/useCountryQuiz.ts` owns the question sequence, answers, and score. They pass state to the map and receive selection events from it.
- **Projection and interaction:** `src/components/WorldMap.vue` coordinates the map. `src/composables/useMapProjection.ts` generates and caches projected paths; `src/composables/useMapZoom.ts` manages the camera. The small policies in `src/logic/mapInteraction.ts` and `src/logic/mapFocus.ts` decide highlight, click, and focus behavior without drawing the map.
- **Drawing:** `src/components/CanvasMap.vue` and `src/workers/mapRaster.worker.ts` paint the default map off the main thread. SVG paths remain for hit-testing and crisp highlights, and can draw the full map as a fallback. `src/components/MarineLabels.vue` draws labels separately; `src/data/mapPalette.ts` keeps canvas and SVG geographic colors in sync.

## Interface styling

The interface follows a shared “pocket atlas” direction: warm paper surfaces, dark ink, Bricolage Grotesque display headings, and Geist controls. Both fonts are locally hosted with licenses and provenance; there are no runtime font-service requests. UI colors, typography, corners, shadows, and common spacing are defined as `--ui-*` tokens in `src/styles.css`; new controls should reuse those roles. Geographic colors remain separate in `src/data/mapPalette.ts` and the map's interaction styles. See [the design audit](docs/design-audit.md) for findings, decisions, and acceptance scope.

## Local releases

Add an **Unreleased** section in `CHANGELOG.md` only when there are pending user-visible changes. When a branch is ready to release, replace that heading with a concise versioned entry so no **Unreleased** heading remains in the published changelog, give major and minor releases a fitting name in the heading, update `package.json` and `package-lock.json` together, and commit the release preparation on that branch. From that clean release branch, run `npm run release:merge`. It checks the version, changelog, and production build, then switches to `main`, merges the branch, and creates an annotated version tag with the release name. Use `npm run release:merge -- --check` to run the checks without merging. The script requires `main` to be an ancestor of the release branch, so integrate any newer `main` changes first. After the local merge, push `main` and the tag when publication is intended; pushing `main` deploys the site through GitHub Pages.
